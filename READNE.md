# lista-01-udwmj
Este repositório contém a resolução da Lista de Exercícios I da disciplina de Usabilidade, Desenvolvimento Web, Mobile e Jogos.

O projeto desenvolvido é uma Calculadora de Média Escolar, criada com HTML5, CSS3 e JavaScript.

⚙️ Funcionalidades do Código JavaScript (script.js)
O algoritmo em JavaScript realiza as seguintes tarefas:

Captura de Dados: Obtém os valores numéricos digitados nos campos de entrada (nota1 e nota2).
Validação: Verifica se os valores informados são números válidos antes de realizar o cálculo.
Cálculo da Média: Utiliza a função calcularMedia() para efetuar a média aritmética simples das duas notas.
Classificação e Feedback:
Média >= 7.0: Exibe status Aprovado (na cor verde).
Média entre 5.0 e 6.9: Exibe status Em Recuperação (na cor laranja).
Média < 5.0: Exibe status Reprovado (na cor vermelha).
Manipulação do DOM: Atualiza o conteúdo e o estilo da página em tempo real conforme a interação do usuário.
🛠️ Tecnologias Utilizadas
HTML5 (Estruturação)
CSS3 (Estilização)
JavaScript ES6+ (Lógica e Interatividade)
