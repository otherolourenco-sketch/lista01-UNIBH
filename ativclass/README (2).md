# Lista 01 - UDMWJ

Resolução da primeira lista de exercícios da disciplina de Usabilidade, Desenvolvimento Web, Mobile e Jogos.

## Calculadora

Calculadora simples com as quatro operações básicas (soma, subtração, multiplicação e divisão), com botões para limpar e apagar o último dígito. Feito com HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` em qualquer navegador e use a calculadora.
